# Личный ИИ-помощник на базе Hermes Agent & Matrix

Современный статический сайт-визитка персонального ИИ-помощника, работающего в экосистеме Nous Hermes и Matrix.

## Особенности
- Дизайн в стиле **Nous Research Hermes** (Electric Blue, Space Grotesk / JetBrains Mono).
- Акцент на архитектуру **Matrix Spaces & Rooms** (изоляция проектов, комнат и сессий).
- Вкладка со списком поддерживаемых моделей и живым поиском.
- Готов к мгновенному деплою на **Cloudflare Pages**.

## Развертывание на Cloudflare Pages
1. Откройте [dash.cloudflare.com](https://dash.cloudflare.com).
2. Перейдите в **Compute (Workers & Pages)** -> **Pages** -> **Create application** -> **Connect to Git**.
3. Выберите репозиторий `zhendosinc-maker/hermes-matrix-site`.
4. Нажмите **Save and Deploy**.
